给 OpenClaw 做了个桌面版

今天学了下 Rust，用 Tauri 给 OpenClaw 做了个桌面应用。踩了个大坑，记录一下。

一直觉得我的 AI 助手 OpenClaw 用起来有点麻烦，每次都要开浏览器、连网关。就想着给它做个桌面应用。

于是今天开始学 Rust，用 Tauri 做了个壳。大概过程：装环境 → 搭项目 → 把 Control UI 嵌进去（用的 WebView2，界面跟网页版一模一样）→ 做托盘图标 → 弄开机自启。

最折腾的是“网关守护”。想加个功能：网关挂了自动重启。结果用 openclaw gateway start 做自动拉起，踩了个大坑——这个命令会先把正在跑的网关杀掉再重启，启动又要 40 秒，检测逻辑以为网关一直没起来，又触发一次……无限循环，网页版就一直显示“gateway 已断开”。搞到凌晨才发现是这行命令的问题。

现在桌面版基本能用了：双击打开、托盘常驻、开机自启。守护逻辑的坑记下了，回头改成“先探测端口，真挂了才拉”。

第一次认真写 Rust，感觉还行。
